# OneID 2.18.1 — System Health Status Icon

**Release date:** 7 October 2026
**Scope:** User dashboard connection and display status indicator

The status-panel trigger uses a heartbeat symbol on a blue gradient. The symbol represents the panel’s combined connection, page-performance, refresh, cache and diagnostic functions.

The trigger retains the session-countdown height and accessible label. The same symbol appears in the header trigger and panel heading on desktop and mobile displays. No login session, SSO token, mobile-production configuration or database behavior changes.
