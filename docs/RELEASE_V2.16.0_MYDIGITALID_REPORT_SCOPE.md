# OneID 2.16.0 — MyDigital ID Report Scope

**Release date:** 6 October 2026  
**Change reference:** `ONEID-V2160-MYDIGITALID-SCOPE-20261006-01`

The MyDigital ID Executive Overview now displays a bilingual scope note. Linked-account totals are a current snapshot, while authentication attempts, successes, rejections, errors and unique users cover the last 30 days.

This clarification changes presentation and release metadata only. It does not alter report queries, calculations or database data.
