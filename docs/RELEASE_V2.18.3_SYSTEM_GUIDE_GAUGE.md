# OneID 2.18.3 — System Guide Gauge Step

**Release date:** 7 October 2026
**Scope:** User dashboard System Guide

System Guide version 2 introduces the coloured Connection and Display Status gauge and explains its connection, page-response, refresh, cache and diagnostic functions.

The guide targets the full gauge button rather than its internal SVG. Fixed-header targets no longer trigger unnecessary mobile scrolling, while scroll, resize and orientation events continue to recalculate the spotlight position. The guide remains bilingual, keyboard accessible and replayable from View System Guide.

No database schema, login session, SSO token or mobile-production configuration changes are included.
