# OneID 2.21.0 — Gauge Direction

Tarikh: 16 Oktober 2026

Susunan gauge prestasi diterbalikkan supaya Fast berada pada zon hijau sebelah
kanan, Moderate pada zon kuning di tengah, dan Slow atau Offline pada zon merah
sebelah kiri. Warna lengkok, formula sudut, kedudukan offline dan cache key
asset dikemas kini bersama supaya paparan konsisten.
