# OneID 2.18.1 — Status Traffic-Light Icon

**Release date:** 7 October 2026  
**Scope:** User dashboard connection and display status indicator

The status-panel trigger now uses a compact traffic-light symbol with red, amber and green lights in a dark housing. It replaces the chart symbol so users can identify the status context more directly.

The trigger retains the session-countdown height and the same accessible label. The symbol is shared by the header trigger and panel heading, and remains responsive on desktop and mobile displays. No login session, SSO token, mobile-production configuration or database behavior changes.
