# OneID 2.13.4 — Product Tour Pengguna

**Tarikh release:** 16 September 2026

Release ini memperkenalkan panduan interaktif pada dashboard pengguna untuk
carian aplikasi, aplikasi kegemaran, tetapan paparan, keselamatan akaun dan
pembaharuan sesi.

Status selesai atau langkau disimpan mengikut akaun serta versi tour supaya
pengguna tidak menerima panduan berulang apabila bertukar browser atau peranti.
Menu **Lihat Panduan Sistem** kekal tersedia untuk membuka panduan secara manual.

Pelaksanaan merangkumi paparan desktop dan mobile, spotlight yang mengikut
lengkungan elemen sasaran, keyboard navigation, reduced motion, CSRF, validasi
server serta migration database tambahan yang boleh dibuat rollback.
