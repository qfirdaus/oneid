# OneID 2.12.2 — User MFA Mode Guidance

The Administrator User MFA mode selector now provides contextual Malay or
English guidance for every mode. The hint explains login enforcement,
self-service availability, temporary restoration and approval requirements.

ENFORCED is clearly identified as the recommended normal mode. OFF carries a
critical warning while explicitly confirming that enrolled factors are
preserved and the independent Maintenance MFA and Admin Step-Up boundaries
remain active.
