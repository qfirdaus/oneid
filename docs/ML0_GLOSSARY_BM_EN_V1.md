## Sempadan canonical

- Exact confirmation phrase tidak diterjemahkan.
- Stable response code, translation key, plan hash, source code, action count,
  approval ID, correlation ID, error code dan audit event tidak diterjemahkan.
- Nama rasmi aplikasi, kategori dan metadata database kekal seperti sumber
  sehingga ML7 menerima approval berasingan.
- Istilah rasmi UPNM mesti disemak semula oleh owner berkaitan sebelum release.

Perubahan selepas pembekuan v1 memerlukan semakan content owner. Perubahan pada
istilah password, OTP, session, Admin Step-Up, ACL, deactivation atau Apply turut
memerlukan security review.
