# OneID 2.12.4 — Login Method Layout

OneID 2.12.4 packages the redesigned login-method layout completed after
version 2.12.3.

The public login page now presents staff and student OneID credentials in a
dedicated card and keeps MyDigital ID as a visually distinct alternative.
Users who do not yet have a MyDigital ID account can open the official
Malaysia portal registration page in a protected new tab. All new copy is
available in Malay and English, and the layout adapts to desktop and mobile
screens.

The existing login form identifier, credential field names, password recovery
action and MyDigital ID endpoint remain unchanged. Administrator and developer
maintenance-login guards are also preserved. This release contains no database
migration and does not change production runtime values or authentication
policy.
